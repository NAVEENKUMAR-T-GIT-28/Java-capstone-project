# User Stories — Smart Clinic Management System

## 1. Admin User Stories

### Story 1: Manage Doctor Profiles
As an Admin, I want to add new doctor profiles so that patients can find doctors and schedule appointments.

### Story 2: View Clinic Users
As an Admin, I want to view registered doctors and patients so that I can oversee clinic operations.

## 2. Doctor User Stories

### Story 1: View Daily Appointments
As a Doctor, I want to log in securely and view my appointment schedule so that I can prepare for consultations.

### Story 2: Manage Availability
As a Doctor, I want to manage my consultation availability so that patients can book suitable time slots.

## 3. Patient User Stories

### Story 1: Search for Doctors
As a Patient, I want to search for doctors by name or specialization so that I can find an appropriate healthcare provider.

### Story 2: Book and View Appointments
As a Patient, I want to book future appointments and view my bookings so that I can manage my clinic visits.
